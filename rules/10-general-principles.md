# Соглашение: Общий принцип

**Когда читать:** перед написанием любого нового класса — первым, до профильного правила по конкретному слою.

**Что описывает:** приоритет «следовать похожему существующему коду» над памятью об общих конвенциях стека, запрет на преждевременное усложнение.

---

## 1. Правило

- Перед тем как писать новый класс — найти в проекте похожий существующий (например, для сервиса — `FrontWordService`/`FrontWordServiceImpl`) и повторить его структуру: пакет, аннотации, стиль Javadoc, импортов. Не изобретать новый стиль по памяти об общих конвенциях Spring.
- Не переусложнять: без абстракций и слоёв «про запас», без TODO/заглушек без необходимости.

## 2. Соглашения для агента

- Это правило читается первым и задаёт приоритет: при конфликте между «как принято в Spring вообще» и «как сделано в соседнем классе этого проекта» — побеждает соседний класс, если только он сам не нарушает профильное правило (`01`–`15`).
- Не вводить новый паттерн, интерфейс или пакет ради единственного текущего случая использования — только когда есть подтверждённая повторяемость (см. правило трёх в `01-layers-and-dependencies.md` про паттерны проектирования).
- Не оставлять TODO без конкретной задачи, к которой он привязан.

## 3. Чек-лист

- [ ] Перед написанием нового класса найден структурно похожий существующий класс в проекте
- [ ] Пакет, аннотации, стиль Javadoc и импортов повторяют найденный образец
- [ ] Нет абстракции/слоя, введённого без подтверждённой необходимости
- [ ] Нет TODO/заглушки без привязанной задачи

## 4. Примеры кода

Создавая, например, `StudentService`/`StudentServiceImpl`, — открыть `FrontWordService`/`FrontWordServiceImpl` как образец и повторить их скелет (пакет, набор Lombok-аннотаций, форму Javadoc, порядок импортов), а не собирать структуру заново по общим воспоминаниям о Spring.

## 5. Когда пересматривать

Это правило не привязано к конкретной технологии и пересматривается только при смене общего подхода к работе с правилами (например, если для новой части проекта явных прецедентов ещё нет и нужно временно ориентироваться только на профильные правила `01`–`15`).
